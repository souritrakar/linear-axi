# Style check

Apply `references/writing-style.md` to the draft. When editing an existing item, first fetch its stored text through `linear issue`, `linear project`, or `linear doc --full`.

Audit in this order:

1. Repeated facts across sections.
2. Nominalizations that should be plain verbs.
3. Formulaic connectors, padding, and restated closers.
4. Titles or openings that repeat the section below.
5. Unverifiable absolutes, negative parallelism, hype, AI vocabulary, filler framing, significance inflation, rhetorical triads, bold-label repetition, hedge stacks, chatbot register, and uniform rhythm.
6. Existing-text accretion: appended updates, resolved questions left behind, superseded facts annotated rather than replaced, and growth unsupported by new scope.

Rewrite only violations and preserve every fact. Re-audit once. Read as a stranger and delete any line whose removal loses no fact, decision, or question. Return the revised text followed by one line per edit; for existing descriptions, include before and after word counts.
