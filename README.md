# linear-axi

A deterministic, token-efficient Linear CLI in the `-axi` style.

`linear-axi` wraps the Linear GraphQL API as predictable, repeatable commands so agents run
Linear operations without the Linear MCP (whose token expires mid-session) or hand-written
GraphQL each call. It is universal across Linear workspaces via per-workspace key profiles.

Status: initial scaffold. Implementation in progress.

See the axi protocol at https://axi.md for output and UX conventions.
